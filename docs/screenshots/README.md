# Portfolio Screenshots

Add real captures to this directory only after verifying that they contain no credentials, Secret values, private email addresses, or unnecessary local machine details.

Expected filenames:

- `admin-dashboard.png`
- `player-view.png`
- `grafana-cluster-overview.png`
- `grafana-allocator-operations.png`
- `prometheus-alerts.png`
- `github-actions-ci.png`
- `github-actions-cd.png`

The root README should embed a screenshot only after its corresponding file exists. Recommended captures should show meaningful platform state rather than empty dashboards, and should keep resource names, release SHAs, and regional capacity readable.
